# 🎮 Мини-Магазин на Python

Консольная текстовая игра с мини-играми, промокодами и внутриигровым магазином. 

> **Что нового в этой версии:** Добавлена полноценная игра "Камень, ножницы, бумага" и исправлены баги!

## ✨ Особенности проекта
* 🎲 **Игра "Угадай число"** — испытай удачу за 3 жизни.
* ✂️ **Игра "Камень, ножницы, бумага"** — классическое противостояние с ботом.
* 💰 **Система экономики** — зарабатывай монеты в играх и трать их в магазине.
* 🧪 **Магазин улучшений** — покупай "Зелье 2х монет", чтобы удваивать свой выигрыш.
* 🔑 **Система промокодов** — вводи секретные коды для получения стартового капитала.

## 🚀 Как запустить игру
1. Склонируйте репозиторий или скачайте файлы `mini_store.py` и `mini_store_shop.txt`.
2. Положите их в одну папку.
3. Запустите игру через терминал:
   ```bash
   python mini_store.py
   ```
