# 🎮 Мини-Магазин на Python

Консольная текстовая игра с мини-играми, продвинутой экономикой, инвентарем и внутриигровым магазином.

🚀 **Что нового в этой версии:**
* 💾 **Система сохранений (save.json):** Теперь прогресс, монеты и инвентарь автоматически сохраняются при любом действии и загружаются при старте!
* 👤 **Новое меню «Профиль»:** Полностью переработан 3-й пункт меню. Теперь там отображается подробный статус аккаунта и индикаторы улучшений.
* 📦 **Автогенерация магазина:** Игра больше не ломается без файла `mini_store_shop.txt` - система сама создаст каталог при первом запуске.
* 💡 **Подсказки в играх:** В игру «Угадай число» добавлены понятные лимиты (от 1 до 15) для удобства игрока.
* 🐛 **Глобальный багфикс:** Исправлен критический баг с лишним ходом при 0 жизней в КНБ и убраны плохие практики (`global` переменные).

## ✨ Особенности проекта
* 🎲 **Игра "Угадай число"** — испытай удачу за 3 жизни с подсказками "больше/меньше".
* ✂️ **Игра "Камень, ножницы, бумага"** — классическое противостояние с ботом с честным подсчетом раундов.
* 💰 **Система экономики** — зарабатывай монеты в играх и трать их в магазине.
* 🛒 **Магазин и Инвентарь** — покупай "Множитель 2x монет" и другие предметы, которые теперь навсегда остаются в твоем профиле.
* 🔑 **Система промокодов** — вводи секретные коды, которые дают повышенный бонус при купленном множителе!

## 🗺️ Планы на будущее (В следующем обновлении)
* 📊 **Выбор сложности:** Настройка уровней сложности для «Угадай число» и «Камень, ножницы, бумага».
* 🎰 **3-я мини-игра:** Добавление полноценного игрового автомата (Слоты) с крутыми комбинациями.
* 🛡️ **Новые предметы:** Расширение магазина (Счастливый амулет, VIP-статус) с уникальными механиками.

## 📦 Как запустить игру
1. Склонируйте репозиторий или скачайте файлы `mini_store.py` и `mini_store_shop.txt`.
2. Положите их в одну папку.
3. Запустите игру через терминал:
```bash
python mini_store.py
```
