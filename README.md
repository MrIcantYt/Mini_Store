# 🎰 Mini-Store

**Mini-Store** — консольная текстовая RPG-игра на Python. Вы играете в казино, покупаете улучшения у загадочного Незнакомца, прокачиваете уровень, открываете новые механики и пытаетесь построить финансовую империю. Работает на Windows и Linux.

## ✨ Возможности

### 🎲 Казино

- **Угадай число** — три уровня сложности, ограниченное число попыток и подсказка «Чётное/Нечётное» со Счастливым амулетом.
- **Камень, ножницы, бумага** — классическая игра против бота.
- **Слоты** — барабаны, редкие символы, джекпот и VIP-ставка `777`.
- **Блэкджек** — дилер, сплит, страховка и ставки `all` / `все`.
- **Рулетка** — красное, чёрное и зеро с высоким множителем.
- **Кости (Craps)** — ставки, повторные броски и тактическая сдача.

### 🛒 Магазин и экономика

- Множители монет и опыта.
- Счастливый амулет и Счастливый тикет.
- Зелье удачи и Кофе для ускорения майнинга.
- Майнинг-ферма с прокачкой до 10 уровня.
- Секретный кейс со случайным исходом.
- Случайная скидка 20% на один товар при входе в магазин.
- Возврат купленных товаров за часть стоимости.

### 📈 Прогресс

- Уровни и опыт: каждый уровень повышает доход.
- Максимальный уровень — 100, излишки XP конвертируются в монеты.
- Ежедневные контракты Торговца с таймером до полуночи, включая бросок 12 в «Костях».
- Квестовая линия Незнакомца.
- Промокод и секретная пасхалка.

### 🏦 Пассивный доход

- Банковский депозит под сложный процент каждые несколько ходов.
- Майнинг-ферма, которая добывает монеты в реальном времени.
- Пассивный бизнес временно отключён.

### 💾 Сохранения

- Прогресс сохраняется в подписанный `game.json`.
- Повреждённое сохранение не загружается и не ломает игру.
- Есть debug-режим с отключённой проверкой подписи.

## 🚀 Как запустить

### Готовые сборки

Готовые бинарники публикуются в разделе [Releases](https://github.com/MrIcantYt/Mini_Store/releases):

- Windows — `mini-store.exe`;
- Linux — исполняемый файл `mini-store`.

На Windows сборка может вызвать предупреждение SmartScreen («Unknown publisher»), потому что файл не подписан цифровым сертификатом. Это нормально для проекта без коммерческой подписи.

### Из исходников

Понадобится [uv](https://docs.astral.sh/uv/) — он сам установит нужную версию Python 3.15. Внешних runtime-зависимостей у игры нет.

```bash
git clone https://github.com/MrIcantYt/Mini_Store.git
cd Mini_Store
uv sync
uv run python -m mini_store
```

### Проверка версии

```bash
uv run python -m mini_store --version
# Mini-Store 0.8.0
```

Для собранного бинарника:

```bash
./mini-store --version
```

## 🎮 Управление

- Пункты меню выбираются вводом номера и нажатием `Enter`.
- В играх ставка вводится числом, словом `all` или `все`.
- В майнинге выход в меню — клавиша `Q`.
- Выход из игры — соответствующий пункт главного меню.

## 💾 Сохранения

Файл `game.json` создаётся в текущей рабочей директории и содержит подписанные данные игрока.

- Если файл повреждён или подпись не совпадает, прогресс будет сброшен.
- Debug-режим запускается с флагом `-d`:
  ```bash
  uv run python -m mini_store -d
  ```
  В нём отключается проверка подписи и появляется пункт Debug menu.
- Сохранения BETA-0.6 в `game.db` не используются. BETA-0.7 и новее работают с `game.json`.

## 📦 Сборка бинарника

Собрать автономный файл через PyInstaller:

```bash
uv run pyinstaller --noconfirm --clean --onefile --add-data "pyproject.toml:." --name mini-store run.py
```

Результат:

- Linux — `dist/mini-store`;
- Windows — `dist/mini-store.exe`.

## 🧪 Разработка

```bash
uv run pytest
uv run ruff check .
uv run ruff format .
uv run ty check
```

Тесты лежат в `tests/`, конфигурация — в `pyproject.toml`.

### Структура проекта

```text
mini_store/
├── __main__.py      # точка входа и главное меню
├── player.py        # игрок, баланс, опыт, уровни
├── shop.py          # магазин
├── sections.py      # профиль, банк, майнинг, контракты
├── db.py            # сохранения
├── sign.py          # подпись JSON
├── deck.py          # карты для блэкджека
├── games/           # игры казино
└── utils/           # меню, ввод, форматирование
tests/               # тесты
run.py               # точка входа для PyInstaller
```
