# Changelog

Все заметные изменения проекта Mini-Store.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версии соответствуют тегам `BETA-0.x`.

## [BETA-0.8] - 2026-11-07

Релиз без новой игровой логики: основная работа — исправление ошибок, найденных при код-ревью, и перевод проекта на Python 3.15.

### Added

- Подсказка «Чётное/Нечётное» от Счастливого амулета в игре «Угадай число».
- Новый ежедневный контракт Торговца: выбить сумму 12 в «Костях» (6 и 6).

### Changed

- Проект переведён на Python 3.15 (`requires-python = "==3.15.*"`).
- Убрана runtime-зависимость `colorama`: ANSI-режим на Windows включается напрямую через `ctypes`.
- Версия игры читается из `pyproject.toml` — единый источник для `--version` и сборки.
- Ruff переведён на `line-length = 100`.
- Код приведён к PEP8, удалены устаревшие комментарии и лишние докстринги.
- Звёздочные импорты заменены явными.
- Терминология приведена к одному виду: «Счастливый тикет».

### Fixed

- Сохранения: `Daily` теперь сохраняется между запусками.
- Сохранения: повреждённый `game.json` больше не роняет игру, прогресс корректно сбрасывается.
- Сохранения: запись выполняется атомарно, файлы читаются и пишутся в `utf-8`.
- Сохранения: старые сейвы без новых полей загружаются через значения по умолчанию.
- Блэкджек: победа снова приносит прибыль, блэкджек оплачивается 3:2.
- Блэкджек: корректно считаются мягкие тузы, пара тузов больше не даёт «выигрышные» 22 очка.
- Блэкджек: ход в банке засчитывается только за завершённый раунд.
- Майнинг: кофе больше не уменьшает задержку до нуля.
- Майнинг и профиль: клавиша `Q` на Linux срабатывает без `Enter`.
- Слоты: VIP-ставка `777` проверяется до списания денег.
- Слоты: прогресс квеста начисляется только за реальную ставку.
- Слоты: XP начисляется через общий механизм с проверкой уровня.
- Экономика: XP после 100 уровня конвертируется в монеты.
- Профиль: на максимальном уровне больше не показывается отрицательный остаток XP.
- Магазин: скидка сохраняется в ежедневных данных и не перекатывается при каждом открытии.
- Магазин: исправлены бизнес, возврат фермы и покупка кофе без фермы.
- Утилиты: `ask_option` не падает на разрывах в нумерации, `HiddenOption` не пересекается с автономером.
- Утилиты: `ask_confirmation` больше не считает согласием любую строку с буквой «д».
- Первый запуск больше не сообщает о сбросе прогресса, если файла сохранения ещё нет.

### Removed

- `SqliteDataBase` и неиспользуемый код.

## [BETA-0.7] - 2026-10-31

### Added

- Новая игра «Кости» (Craps) со ставками и тактической сдачей.
- Сплит и страховка в блэкджеке.
- Банковский депозит под сложный процент.
- Ежедневные контракты Торговца с таймером до полуночи.
- Множители монет и опыта до 5x.
- Случайная скидка 20% на товар при входе в магазин.
- Возврат товаров за часть стоимости.
- Тесты на pytest, линтер Ruff, проверка типов `ty` и CI.
- Сборка автономных бинарников через PyInstaller.
- Флаг `--version` для вывода версии игры.

### Changed

- Проект переведён на пакетную структуру `mini_store/`.
- Магазин вынесен в отдельный класс `Shop`.
- Игры получают общий `GameContext`.
- Квесты перенесены в профиль игрока.
- Промокод перенесён на цифру 9 и скрывается после использования.
- Сохранения переведены на подписанный `game.json`.
- Debug-режим запускается флагом `-d`.

### Fixed

- Сохранение первого игрока в JSON.
- Начисление XP и повышение уровня.
- Баланс больше не может стать отрицательным.
- Таймер контрактов теперь учитывает часовой пояс.
- Исправлены ошибки типизации и импортов.

### Removed

- Dockerfile и упоминания контейнеризации.
- Неиспользуемая зависимость `cryptography`.
- Временная механика пассивного бизнеса.
